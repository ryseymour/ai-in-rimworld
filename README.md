# AI in Rimworld

Project folder for the "AI in Rimworld" project.

## Structure

- `resources/` — reference material, links, source files, and assets.
- `wiki/` — project knowledge base. Start with `wiki/project-direction.md`.
- `backlog/` — tasks, ideas, and work items to be prioritized.
- `mod/` — RimWorld C# mod (see `mod/README.md`).
- `orchestrator/` — Python orchestrator and dashboard (see `orchestrator/README.md`).
